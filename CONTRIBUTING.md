# Collaborare

1. Consultare README e docs/PIANO-GRUPPO.md.
2. Aprire una issue descrivendo risultato, responsabile, scadenza e dipendenze.
3. Per modificare il codice, creare un branch `codex/descrizione` o un branch del gruppo e proporre una pull request.
4. Per le ricerche usare ricerche/MODELLO.md.
5. Verificare manualmente il percorso interessato e descrivere l'esito nella pull request.

Non inserire chiavi API, password, dati reali degli studenti o file di configurazione privati. Le autorizzazioni d'accesso al repository sono gestite dal proprietario.
