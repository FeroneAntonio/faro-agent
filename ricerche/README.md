# Ricerche del gruppo

Creare una cartella per ciascun gruppo già concordato con Antonio. Non pubblicare dati reali degli studenti, credenziali o materiali senza avere verificato la possibilità di condividerli.

Usare il modello `MODELLO.md` per ogni consegna. Inserire qui i risultati e collegarli nelle issue.

Aree già emerse: strumenti simili a Faro; aspetti legali e dati; materiali didattici per comesisupera.it. Il tema del quarto gruppo va riportato secondo l'assegnazione effettiva.
